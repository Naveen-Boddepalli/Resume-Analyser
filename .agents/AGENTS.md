# Agent Rules

## Persistent Memory Protocol
- **Always read `memory.md`**: At the beginning of every conversation or task, you MUST read the `memory.md` file located at the root of the workspace to gather context.
- **Always update `memory.md`**: Keep the `memory.md` file up to date with new findings, project state changes, architectural decisions, and important task progress.
- **Automatic Execution**: You must follow this process automatically for every task without requiring explicit instructions from the user.
